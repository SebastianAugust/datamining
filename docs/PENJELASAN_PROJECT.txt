UTS Data Mining - Klasterisasi Unsupervised pada Pump Sensor Data
==========================================================================

1. GAMBARAN BESAR
-----------------
Tujuan : mengelompokkan (clustering) kondisi operasi pompa industri dari data sensor,
         tanpa label (unsupervised).
Dataset: Pump Sensor Data (Kaggle: nphantawee/pump-sensor-data)
Status : yang sudah selesai baru Tahap 2 (data understanding + data cleaning + analisis
         karakter data). Windowing (Tahap 3) dan klasterisasi sendiri BELUM dikerjakan di repo ini.
Pertanyaan yang dijawab sejauh ini: "data ini seperti apa, bolong di mana, dan
         bagaimana menyiapkannya supaya layak dipakai untuk klasterisasi time-series?"

2. DATASET
----------

4. MASALAH DATA KOSONG (inti perbaikan K2/K3)
---------------------------------------------
Temuan pada data mentah:
 - sensor_15 kosong 100% -> dibuang
 - sensor_50 mati permanen sejak 2018-07-09 (35% kosong) -> dibuang
 - sensor_51 punya celah ~10,7 hari di Juni -> dibuang
 - sensor_00, 06, 07, 08, 09 punya celah panjang yang waktunya sering sama (mis. 30 Juni)
 - 456 celah kosong total; 96% di antaranya <= 15 menit (glitch sesaat)

Kesalahan versi lama: semua celah diisi interpolasi linier. Celah 4 hari diisi garis
lurus -> data palsu, ACF menggelembung.

Solusi versi baru:
 - celah pendek (<= 15 menit) : interpolasi linier (aman, kemungkinan glitch)
 - celah panjang (> 15 menit) : dibiarkan kosong (NaN). Jujur terhadap data.
 - Jangan pakai interpolate(limit=N): itu hanya mengisi N baris pertama celah dan
   meninggalkan potongan garis lurus di ujungnya.
Mengapa 15? 96% celah <= 15 menit. Ekor distribusi kontinu, jadi ini batas praktis,
bukan pemisah alami. Hasil tidak sensitif (15 -> 60 menit cuma ubah 294 dari ~10,8 juta
sel). Nilainya bisa diubah di notebooks/common.py.

Konsekuensi NaN yang tersisa: tiap analisis harus menanganinya secara eksplisit:
 - statistik/outlier : pakai nilai yang ada per kolom
 - korelasi          : pairwise
 - ACF               : di dalam segmen kontigu tanpa NaN (tidak melintasi celah)
 - PCA               : hanya baris lengkap (94,84% baris tersisa, cukup)
 - nanti di windowing: window yang terlalu banyak NaN dibuang

5. ANALISIS KARAKTER DATA (hasil)
---------------------------------
Korelasi : 183 pasangan sensor dengan |r| > 0,7 -> banyak sensor redundan, cocok untuk
           reduksi dimensi.
PCA      : PC1 36,1%, PC2 16,9% (total 53%); butuh 15 komponen untuk 90% varians ->
           struktur data cukup tersebar, tidak hanya 2 dimensi.
ACF      : semua 49 sensor punya ACF lag-1 > 0,9 -> nilai sekarang sangat bergantung pada
           menit sebelumnya (data sangat persisten). ACF multi-skala: ketergantungan
           menurun saat data diagregasi ke skala lebih kasar (sensor_00: 0,99 pada 1 menit
           jadi 0,93 pada 60 menit).
ADF      : 48 sensor stasioner, 1 tidak (sensor_02). Catatan: n sangat besar sehingga uji
           mudah menolak H0; artinya "tidak ada bukti unit root", bukan "tanpa tren".
Diff     : setelah diff orde 1, ACF lag-1 turun > 0,5 pada 38 sensor -> sebagian besar
           ketergantungan tinggi berasal dari tren/level, bukan gerakan jangka pendek.
           11 sensor (38-49 kecuali 44) tetap 0,66-0,81; penyebab belum diselidiki.
Implikasi: karena data sangat persisten, klasterisasi per-baris akan menganggap menit
           berdekatan "mirip" secara otomatis. Pertimbangkan windowing dan/atau fitur
           perubahan (diff) di Tahap 3.

8. ISTILAH PENTING
------------------
 Interpolasi linier : mengisi nilai kosong dengan garis lurus antara dua nilai di
                      sisi celah.
 Celah (gap)        : deretan menit berurutan yang kosong pada satu sensor.
 ACF                : korelasi sebuah deret dengan dirinya sendiri pada selisih waktu
                      (lag) tertentu. Tinggi = nilai sekarang mirip nilai sebelumnya.
 ADF                : uji stasioneritas; H0 = ada unit root (tidak stasioner).
 Diff orde 1        : x(t) - x(t-1); membuang tren/level.
 PCA                : reduksi dimensi; menyisakan arah dengan varians terbesar.
 Pairwise           : korelasi tiap pasangan dihitung dari baris yang kedua nilainya ada.
 Unsupervised       : tanpa label; machine_status tidak dipakai untuk melatih/memutuskan.
